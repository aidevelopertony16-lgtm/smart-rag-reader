# 📄 Smart RAG Reader | الروبوت القارئ

An intelligent AI assistant that reads a specific document and answers questions based *only* on the provided text, preventing AI hallucinations.
مساعد ذكي يقرأ مستنداً معيناً ويجيب على الأسئلة بناءً على النص فقط، مما يمنع "هلوسة" الذكاء الاصطناعي.

## 🚀 Features | المميزات
* **Context Grounding:** Answers are strictly based on the provided document. (الإجابات مبنية حصرياً على المستند المرفق).
* **No Hallucinations:** If the answer is not in the text, it says "Information not found". (إذا لم تكن المعلومة موجودة، يخبرك بذلك بدلاً من اختراعها).
* **Secure:** Uses environment variables for API protection. (يستخدم متغيرات بيئة لحماية المفاتيح).
